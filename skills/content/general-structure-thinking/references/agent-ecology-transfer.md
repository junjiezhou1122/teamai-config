# Agent Ecology Transfer Reference

Use this when mapping structures into agent ecology.

## Core ecology model

```text
private context
  -> communicated context
  -> externalized shared context
  -> selective retrieval
  -> action
  -> feedback
  -> memory update / decay
```

Agent ecology should focus on context flow, shared substrates, trace learning, pattern retention, and dynamic routing rather than fixed multi-agent roles.

## Design questions

- What context should remain private?
- What should be communicated temporarily?
- What should be externalized as artifact?
- What should become canonical?
- What should be quarantined?
- What should decay?
- What is the source of truth?
- What trace will update future routing?
- What frame/taste/rubric should be activated?
- What minimal experiment can falsify the design?

## Common transfers

- market price -> artifact salience / agent trust / context cost
- Git history -> artifact lineage / provenance log
- scientific citation -> claim-evidence ledger
- immune system -> quarantine / anomaly detection / adaptive memory
- OS scheduler -> dynamic agent/tool/context routing
- cache hierarchy -> hot/warm/cold context
- code review -> evidence-gated promotion
- postmortem -> failure-boundary card
- hospital triage -> risk-based routing
- distributed consensus -> canonical memory write quorum

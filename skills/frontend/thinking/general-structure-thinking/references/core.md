# Core Reference: General Structure Thinking

## Core thesis

Intelligence scales through structured coordination under bounded context.

```text
bounded local processors
  + selective communication
  + shared external state
  + feedback and selection
  + memory, decay, and revision
  -> scalable organized intelligence
```

## First principles

- attention is finite
- context is finite
- memory is fallible and stale
- communication has cost
- observation is local
- state is distributed
- agents are fallible
- feedback is delayed and noisy
- actions are interdependent
- resources are scarce
- scale creates phase transitions
- adaptation requires variation, selection, and retention

## Thinking operators

- trade-off: what cannot be maximized together?
- breakdown: when does this fail?
- bottleneck: what truly limits throughput or quality?
- invariant: what must remain true?
- boundary: where should inside/outside be drawn?
- coupling: what changes together?
- feedback: how does the system learn it was wrong?
- representation: what form makes the problem tractable?
- source of truth: what wins during conflict?
- phase transition: what changes at 10x scale?
- reversibility: can this be undone?
- signal vs noise: what evidence is meaningful?
- credit assignment: what caused success/failure?
- path dependence: what early choices lock in future paths?
- entropy/maintenance: how does this decay without care?
- granularity: what is the right unit size?

## Frames

Frames select ontology, variables, causal model, values, and blind spots.

Useful frames:

- market: scarcity, price, demand, incentives, revealed behavior
- memory: persistence, freshness, provenance, source of truth, decay
- network: nodes, edges, hubs, bridges, robustness, diffusion
- security/immune: threat, attack surface, quarantine, containment
- distributed systems: state, messages, consistency, latency, failure, logs
- ecology: niche, competition, symbiosis, succession, adaptation
- science/evidence: claim, evidence, replication, falsification
- organization: roles, ownership, governance, coordination, incentives
- software architecture: interfaces, modules, dependencies, boundaries
- cognitive science: attention, salience, working memory, global workspace

## Taste and tacit knowledge

- Frame decides what variables are visible.
- Taste decides what good looks like.
- Mental model connects variables causally.
- Tacit knowledge is implicit compressed experience.
- Aha moment is when hidden structure becomes explicit.

Knowledge maturation:

```text
experience
  -> tacit knowledge
  -> taste / smell / intuition
  -> aha moment
  -> explicit frame / principle
  -> general structure
  -> pattern card
  -> rubric / doctrine
  -> mechanism
  -> experiment
  -> retained organizational memory
```

## Price-like / revealed signals

A price-like signal is a compressed public coordination signal from distributed behavior.

```text
private distributed state
  -> revealed actions
  -> aggregated public signal
  -> future allocation
  -> feedback and update
```

Examples for agent ecology:

- artifact salience
- agent trust
- context cost
- task urgency
- memory freshness
- verification need
- source reliability

Do not confuse salience with truth.
